# Logos de equipamiento — cinta de la home

Estos archivos alimentan la cinta de logos de `index.html` (escala de grises → color al pasar el ratón).

## ⚠️ Son PLACEHOLDERS
Cada `.svg` es solo el nombre de la marca en color, para ver el montaje. **Sustitúyelos por los logos oficiales** manteniendo el mismo nombre de archivo (p. ej. `lode.svg`).

## Cómo añadir los logos reales
- Formato: **SVG** (ideal) o **PNG con fondo transparente**.
- Usa la **versión en color** del logo: la web aplica el gris automáticamente y revela el color al hover.
- Altura de referencia ~34 px; anchos similares quedan más ordenados.
- Nombres de archivo actuales: lode, cosmed, delsys, tforce, chronojump, firstbeat, garmin, elite, rogue, kabuki.
- Para añadir/quitar marcas: añade el archivo aquí y su `<img>` en la cinta de `index.html` (sección "LOGO STRIP").

## Nota de marca
Mostrar logos de marcas de equipamiento como "equipamiento con el que trabajamos" es un uso informativo legítimo, pero usa los logos oficiales y respeta las guías de marca de cada fabricante.
